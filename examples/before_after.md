# 前後對照：同一題，沒接與接上免費會計助手

同一個模型（Claude Sonnet 5.5）回答同一題，比兩種情況：

- **沒接**：不給任何工具（沒有網頁搜尋、沒有讀檔或執行指令）、不接 MCP，只靠模型自己記得的規則與數字。
- **接上**：只接免費會計助手（與線上同一版資料），不能上網。

**這幾題是挑出來的例子，不代表整體答對率；整體數字見 [README 的總表](../README.md#效果有多少總表)。**

怎麼挑、怎麼測：

- 2026-10-30 實測。每題兩種情況各答 2 次，**沒接的 2 次都算錯錢、接上的 2 次都算對**才放進來；兩次結果不一樣的題目不用。
- 作答方式同 README 的題目評測：每題一個獨立的非互動 Claude Code，工作目錄是空的，題目裡的「今天」固定。
- 「接上之後」的金額，另外直接呼叫線上的工具重算一次，數字一樣才用。
- 「沒接」那一行是答卷原文的**節錄**（「」裡逐字照抄，標點也照原樣），不改寫。
- 金額都是元。

## 1. 薪資扣繳：月薪 80,000 元要扣多少

**題目**：2026 年，居住者員工月薪 80,000 元（單身，無眷屬、無受扶養親屬、未申報扣繳稅額表以外項目）。每月薪資扣繳稅額多少元？

| | |
|---|---|
| **沒接** | 每月約 **2,142**（第 2 次約 2,067）。兩次都說查不到 115 年度的稅額表，用估算。節錄：第 1 次「約為 2,142 元/月」；第 2 次「約 2,067 元;若表仍沿用 114 年度參數則約 2,142 元。」 |
| **接上** | 查 115 年度薪資所得扣繳稅額表，無配偶及受扶養親屬、月薪 80,000 元：**0**（工具 `calc_withholding_and_nhi_supplement`）。 |
| **為什麼** | 薪資所得扣繳辦法第 5 條第 1 項：按月給付、已填免稅額申報表的薪資，按薪資所得扣繳稅額表的表列稅額扣取；115 年度表上這一列是 0 元。 |
| **差多少** | 每月多扣 **2,142** 元（第 2 次是 2,067），一年 25,704 元。 |

## 2. 勞保：月中到職，當月保費按幾天算

**題目**：2026 年 10 月 16 日到職，月投保薪資 36,300 元。10 月份勞保勞工自付（含就保）與雇主負擔各多少元？（以 30 日按日計）

| | |
|---|---|
| **沒接** | 勞工 **504**、雇主 **1,762**（算成 16 天、普通事故費率 12%）。節錄：第 1 次「10 月投保 16 天（16/30）」「勞工自付 504 元（勞保 465 元＋就保 39 元）」「雇主負擔 1,762 元（勞保普通事故 1,626 元＋就保 136 元）」；第 2 次同樣 504、1,762，另列「若把到職日起算改成 15 天（30－16+1），則勞工自付 472 元，雇主負擔 1,652 元」，費率仍用 12%。 |
| **接上** | 投保 15 日（每月以 30 日計，10/16 到 10/30）；勞保局 115 年分擔金額表：勞工 417 + 36 = **453**、雇主 1,461 + 127 = **1,588**（勞保＋就保，不含職災；工具 `calc_labor_health_insurance`）。 |
| **為什麼** | 勞工保險條例施行細則第 28 條之 1 第 1 項：「本條例第十三條第一項所定保險費，每月以三十日計算。」勞工保險條例第 11 條：保險效力自到職通知的當日起算；勞保局的保費計算說明：加保當日起算、大月的 31 日不另計，所以是 30 − 16 + 1 = 15 日。普通事故費率 115 年實收 11.5%、加就業保險 1%（勞工保險條例第 13 條、就業保險法第 8 條，勞保局公告）。 |
| **差多少** | 勞工多扣 **51** 元，雇主多算 **174** 元。 |

## 3. 勞保：月中離職，當月保費

**題目**：2026 年 10 月 20 日離職並退保（最後在職日 10 月 20 日），月投保薪資 40,100 元。10 月份勞保勞工自付（含就保）與雇主負擔各多少元？

| | |
|---|---|
| **沒接** | 勞工 **695**、雇主 **2,433**（天數 20 天對，費率用 12%）。節錄：第 1 次「勞保勞工自付（含就保）為 695 元。雇主負擔（普通事故＋就保）為 2,433 元」；第 2 次「普通事故 12%、就業保險 1%，費率為記憶中的數字，尚未查證」「10 月勞保勞工自付 695 元（勞保 642 元 + 就保 53 元）；雇主負擔 2,433 元」。 |
| **接上** | 投保 20 日（算到退保當日）；勞保局 115 年分擔金額表：勞工 615 + 53 = **668**、雇主 2,152 + 187 = **2,339**（勞保＋就保，不含職災；工具 `calc_labor_health_insurance`）。 |
| **為什麼** | 普通事故費率 115 年實收 11.5%，不是 12%（勞工保險條例第 13 條，勞保局公告）；就業保險 1%（就業保險法第 8 條）。天數：勞保局的保費計算說明，退保當日也計收，10/1 到 10/20 共 20 日（勞工保險條例施行細則第 28 條之 1 第 1 項，每月以 30 日計算）。 |
| **差多少** | 勞工多扣 **27** 元，雇主多算 **94** 元。 |

## 4. 勞保：部分工時工讀生的保費

**題目**：2026 年，工讀生（部分工時）月薪 8,000 元。勞保月投保薪資應申報為多少？勞保勞工自付與雇主負擔各多少元（暫以普通事故、就保、職災合計）？

| | |
|---|---|
| **沒接** | 投保薪資 11,100 對；勞工 **288**、雇主 **1,010**（普通事故費率用 12%；職災因題目沒給行業別，兩組都沒算）。節錄：第 1 次「勞工自付 288 元（普通事故 266 元 + 就保 22 元，職災勞工不負擔）」「雇主負擔普通事故 932 元 + 就保 78 元 = 1,010 元」；第 2 次「勞工自付 288 元（普通事故 266 + 就保 22），雇主負擔 1,010 元（普通事故 932 + 就保 78）」。 |
| **接上** | 投保薪資 11,100（部分工時）；勞保局 115 年分擔金額表：勞工 255 + 22 = **277**、雇主 894 + 78 = **972**（勞保＋就保；工具 `calc_labor_health_insurance`）。職災費率看行業別，題目沒給，兩組都不含職災。 |
| **為什麼** | 普通事故費率 115 年實收 11.5%，不是 12%（勞工保險條例第 13 條，勞保局公告）；就業保險 1%（就業保險法第 8 條）。 |
| **差多少** | 勞工每月多扣 **11** 元，雇主每月多算 **38** 元。 |
